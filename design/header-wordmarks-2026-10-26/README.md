# Header-Schriftzüge · 26.10.2026

Mit dem eingebauten ImageGen erstellt, abgeleitet aus dem Raster-Schriftzug im Figma-Frame „Eat This. / eat this. · Zentrierter Vergleich“ (2149:25738). Die Vorlage enthält keine verwendbare Fontdatei.

- menu.png: transparenter Schriftzug „Menü“
- map.png: transparenter Schriftzug „Map“
- Figma-Vergleich: https://www.figma.com/design/p5XEjPCeGlgtXxhreeIgnB/Eat-This?node-id=2357-27756

Prompt je Wort: Ein einzelner schwarzer Header-Schriftzug „Menü“ bzw. „Map“, basierend auf den massiven, kompakten, leicht unregelmäßigen Grotesk-Buchstaben von „Eat This.“ im Referenzbild. Enge Laufweite, aufrechte Formen, klare Lesbarkeit in kleiner Headergröße, transparente Fläche, keine Papierstruktur, keine Schatten, kein Zusatztext. Bei Menü zwei klar erkennbare Umlautpunkte.

Die PNGs enthalten transparente Ränder. In Figma werden sie über beschnittene Frames auf die sichtbaren Buchstaben begrenzt. In der App liegen sie beschnitten als WebP unter `nextjs/public/pics/navigation/` (`HeaderWordmark`).
