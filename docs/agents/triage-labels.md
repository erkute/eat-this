# Triage Labels

Die Skills sprechen von fünf Rollen für den Stand eines Tickets. Im Ticket-Repo `erkute/eat-this-tickets` heißen die Labels genauso.

| Rolle in mattpocock/skills | Label im Ticket-Repo | Bedeutung                                       |
| -------------------------- | -------------------- | ----------------------------------------------- |
| `needs-triage`             | `needs-triage`       | Muss noch angesehen werden                      |
| `needs-info`               | `needs-info`         | Wartet auf mehr Infos                           |
| `ready-for-agent`          | `ready-for-agent`    | Klar beschrieben, Claude kann es allein bauen   |
| `ready-for-human`          | `ready-for-human`    | Braucht die Projektleitung (Entscheidung, Test) |
| `wontfix`                  | `wontfix`            | Wird nicht gemacht                              |

Die Art steht über `bug` (etwas ist kaputt) oder `enhancement` (neu oder besser).
